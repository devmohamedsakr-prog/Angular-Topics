# Security Policy

## Supported Versions

This project is a learning resource for Angular development. Security updates are applied to the main branch.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | Yes                |
| Main    | Yes                |

## Reporting a Vulnerability

Security is important to us. If you discover a security vulnerability in this learning resource, please report it responsibly.

### How to Report

1. **Do not open a public GitHub issue** for security vulnerabilities
2. Email security details to: devmohamedsakr-prog@gmail.com
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce (if applicable)
   - Potential impact
   - Suggested fix (if available)

### Response Timeline

- Initial response: Within 24 hours
- Assessment: Within 48 hours
- Fix/Disclosure: Within 7 days

## Security Guidelines for Users

This repository contains educational content and code examples. When using code from this resource:

1. **Review all code before use** - Verify examples suit your security requirements
2. **Keep dependencies updated** - Use current versions of Angular and related packages
3. **Follow best practices** - Apply Angular security guidelines from official documentation
4. **Test thoroughly** - Validate code in your environment before production use
5. **Report issues** - Help us improve by reporting security concerns

## Code Security

All code examples in this repository follow Angular security best practices:

- Input sanitization and validation
- Output escaping and encoding
- CSRF protection patterns
- XSS prevention techniques
- Secure component communication
- Safe HTTP request handling
- Authentication and authorization patterns

## Contributing Securely

When contributing to this project:

1. Do not commit secrets, API keys, or credentials
2. Use environment variables for sensitive configuration
3. Follow security guidelines in CONTRIBUTING.md
4. Test code for common vulnerabilities
5. Document security considerations in pull requests
